# 체육수업 운영 도우미

**오늘체육뭐해요(@WhatsPEtoday)가 제작한 교사용 무료 수업 운영 프로그램입니다.**

팀을 만든 뒤 같은 명단으로 토너먼트·리그·제비뽑기를 이어서 운영합니다. 판서·스톱워치와 같은 Wi-Fi의 심판 기기 연결을 함께 사용할 수 있습니다.

## 다운로드

### [최신 Windows 실행용 ZIP 다운로드 페이지](https://github.com/hongbin56/pe-class-helper/releases/latest)

[Windows 실행용 ZIP 바로 받기](https://github.com/hongbin56/pe-class-helper/releases/latest/download/PE-Class-Helper-v1.0.14-windows-x64.zip)

**현재 버전: v1.0.14 / Windows 10·11 64비트 / Python 설치 불필요**

1. 위 페이지의 **Windows 실행용 ZIP**(`PE-Class-Helper-v1.0.14-windows-x64.zip`)을 내려받습니다.
2. 압축을 완전히 풀고 `프로그램_실행.bat` 또는 `체육수업_운영도우미.exe`를 실행합니다.
3. 학생 명단에서 빈 Excel 양식을 받아 작성·업로드하거나 가상 예제로 먼저 확인합니다.

GitHub의 **Code → Download ZIP**, **Source code (zip)**은 이 소개 저장소의 문서이며 실행 프로그램이 아닙니다. 실행용 ZIP을 선택하세요. `_internal` 폴더를 포함한 압축 해제 파일을 함께 보관해야 합니다.

## 주요 기능

- 반별·여러 반 합동 팀 편성, 남녀 균형·분리, 결석자 제외, 팀원 이동.
- 편성한 명단으로 토너먼트·풀리그·제비뽑기 연결.
- 토너먼트 승자 진출, 부전승, 남녀 경기부, 큰 대진표와 TV용 가로 출력.
- 리그 경기장별 일정·점수·무승부·순위 계산.
- Windows 교사 PC와 같은 허용된 Wi-Fi의 심판 기기 **2~4대** 연결, QR 접속·경기장/경기부 배정·결과 반영.
- 가벼운 판서, 선수 자석, 코트 배경, 스톱워치.
- 수업 저장·불러오기, 명단 Excel 및 결과 이미지·Excel 내보내기.

## 시작 전 확인

공식 ZIP은 빈 명단과 가상 예제만 포함합니다. 학생 정보는 개발자 서버로 자동 전송하지 않습니다. Wi-Fi 심판 연결은 교사 PC가 로컬 서버가 되는 선택 기능이며, 이름 공유·보관 위치·HTTP 통신의 한계는 [개인정보 안내](PRIVACY.md)를 확인하세요.

이번 배포본은 [197개 자동 테스트와 실제 Windows 실행 파일 검증](VERIFICATION.md)을 통과했습니다. 실제 학교 Wi-Fi와 물리적 태블릿 4대 환경은 현장 확인이 필요합니다.

디지털 서명이 없는 ZIP입니다. GitHub에 게시됐다는 사실이나 SHA-256이 바이러스 인증·학교 사용 승인을 뜻하지 않습니다. Windows 또는 학교 정책에서 제한하면 보안 설정을 끄지 말고 담당자에게 확인하세요.
